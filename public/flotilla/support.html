Flotilla — Support

Flotilla is a native iOS client for Unraid and Proxmox VE.

Common setup notes

  • Unraid: create an API key in Settings → Management Access → API, then add the server with its LAN address (HTTPS, port 443).
  • Proxmox VE: create an API token (Datacenter → Permissions → API Tokens) with PVEAuditor + PVEVMAdmin, port 8006. If privilege separation is on, grant the token the same roles.
  • Self-signed certificates are pinned on first connect — if you replace a server's certificate, re-approve it from Settings → the server → endpoint list.
  • Away from home: add your Tailscale address as a remote endpoint (Settings → server → Endpoints).
